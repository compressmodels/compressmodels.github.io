Keep defect classification from slowing inspection down.

In high-speed inspection, image processing can take longer than the mechanical inspection cycle itself. When defect classification and pattern recognition become the slowest step, the system's ability to turn captured images into results can limit overall throughput. Moco helps increase classifier throughput by identifying opportunities to finish classification earlier.

More efficient processing of inspection images
01 / The problem

Image analysis can take longer than inspection.

Mechanical systems move wafers and inspection optics through their planned cycle. But the images they generate still need to be processed. Defect classification and pattern recognition can require enough computation that analysis outlasts the mechanical inspection cycle.

THE MECHANICAL CYCLE

Inspection keeps moving

Wafer positioning and image capture proceed through the inspection sequence, generating data that must be analyzed.

THE COMPUTATIONAL CYCLE

Classification takes longer

Image-processing algorithms evaluate defects and recognize patterns. When this work exceeds the mechanical cycle time, processing can become a throughput bottleneck.

The gap between image capture and classification

When analysis cannot keep pace with inspection, captured images accumulate faster than the classifier can complete its work.

02 / The solution

Moco helps classifiers reach decisions sooner.

Moco identifies early-exit opportunities in classifiers. When an inspection input can be classified with sufficient confidence at an earlier stage, it can exit without continuing through every subsequent stage. Inputs that need more evaluation continue deeper into the classifier.

ILLUSTRATIVE CLASSIFICATION FLOW
Inspection imageEnter defect classifier
Early exitSufficient confidence
Continue analysisMore evaluation needed

The path depends on the classifier and its configured decision criteria.

✓

Increase classifier throughput

Reduce avoidable computation so more inspection images can be classified over time.

✓

Shorten unnecessary processing

Allow inputs that are ready for a confident classification to finish before the full processing path.

✓

Reserve deeper analysis when needed

Inputs that do not meet early-exit criteria can continue through additional classifier stages.

Make image classification more efficient, so processing is less likely to hold back inspection throughput. Moco focuses on computation inside the classifier—the specific processing bottleneck described here. It does not change the mechanical inspection cycle or the image-capture hardware.

Actual impact depends on the classifier, inspection images, confidence criteria, and workload. No numerical performance improvement is implied.
