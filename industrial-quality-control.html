Inspect more. Keep quality in focus.

Advanced manufacturing depends on fast, reliable inspection. As wafer imaging becomes more detailed and defect analysis more demanding, the computing required to classify inspection data can become a constraint on overall throughput. Moco helps address that challenge by finding opportunities to complete classification earlier.

More efficient classification for demanding inspection workloads
01 / The problem

Inspection throughput is constrained at multiple points.

Wafer inspection brings optics, precision mechanics, image processing, and system controls together in a tightly coordinated workflow. A delay in any one area can limit the rate at which inspection results become available.

01 — OPTICS & MECHANICS

Resolution takes time

High-sensitivity imaging can require longer exposures and substantial data capture. Precise wafer handling and stage movement also add time as the system moves between inspection locations.

02 — IMAGE PROCESSING

More data to analyze

High-resolution inspection generates large image volumes. Defect classification and pattern recognition can demand significant computation, potentially making analysis a limiting step in the inspection cycle.

03 — SYSTEM INTEGRATION

Subsystems must stay in sync

Illumination, optics, motion control, handling, and processing must operate together. Coordination delays and inefficient resource allocation can prevent multi-beam systems from fully using their parallel capacity.

04 — OPERATIONS & COMPLEXITY

Consistency adds overhead

Thermal management, vibration control, and calibration can interrupt inspection. As device structures and defect requirements become more complex, analysis can also take longer.

The opportunity: improve the computational part of the inspection path.

Optical capture, wafer motion, system coordination, and operating conditions all matter. But once inspection data reaches a classifier, not every input necessarily needs the same depth of computation.

02 / The solution

Moco helps classifiers do less work when less is enough.

Moco identifies early-exit opportunities in classifiers. When an input can be classified with sufficient confidence at an earlier stage, it can exit without continuing through every subsequent stage. Inputs that need more evaluation continue deeper into the classifier.

Target a key software bottleneck

Improve classification efficiency within the inspection workflow without implying changes to optical capture or wafer-handling speed.

Higher classifier throughput can help inspection systems make better use of their data-processing capacity. Moco focuses on the computational work inside classification. It is one part of a broader inspection system, alongside optics, mechanics, orchestration, calibration, and process control.

Actual impact depends on the classifier, inspection data, confidence criteria, workload, and system integration. No numerical performance improvement is implied.
