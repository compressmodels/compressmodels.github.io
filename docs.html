Purpose of moco

moco takes machine learning models and optimizes them for computational efficiency with no accuracy loss.

moco analyzes data to find early-exit strategies to exploit:

  • moco analyzes the input data. An example early-exit rule for a fraud detection model (when the features are interpretable) might be: "it's fraud if the user has logged in 4 times in the last 10 minutes."
  • Intermediate representations (often referred to as embeddings, activations, etc.)

Form Factor

moco is a pip-installable Python package that offers a helper library that wraps models in early-exit gates. It is supported by a set of API endpoints, available remotely that offer proprietary algorithms for finding rules.

Early-Exiting

The early-exit algorithm involves an initial analysis step to analyze an embedding and a set of corresponding predictions. The analysis algorithm outputs a hyperplane that on one side is homogenous with respect to a certain class. At runtime, an input comes in and if the input is on the + side of the hyperplane, the corresponding class is outputted otherwise the original model is executed. Savings come from the fact that the full model is not always executed.
